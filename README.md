# Svelte 5 Spatial Sandbox

Interactive spatial data UI sandbox built with **Svelte 5 Runes**, **TypeScript**, and **Vite**.

## Quick Start

```bash
# Install dependencies
pnpm install

# Start local development server (http://localhost:5173)
pnpm dev

# Type check & production build
pnpm check
pnpm build
```
